# Что писать агенту

Фразы для чата с агентом и что произойдёт. Технические параметры вызовов — в [tool-parameters.md](tool-parameters.md).

Агент ждёт завершения операции и показывает результат — отдельно просить об этом не нужно. Если хочется смотреть ход выполнения в терминале, скажите «запусти в терминале, не жди результата».

## Окружение и профили запуска

| Что написать | Что произойдёт |
|---|---|
| Покажи состояние окружения 1С | Версия vanessa-runner, активный профиль, файл настроек, база, временные параметры |
| Переключись на профиль test | Профиль станет активным для всех следующих команд, статус-бар обновится |
| Переключись на профиль qa | Если такого нет — ответ со списком доступных профилей |

## Тесты

| Что написать | Что произойдёт |
|---|---|
| Запусти vanessa-тесты | Прогон сценариев активного профиля, в ответе счётчики и упавшие тесты |
| Запусти vanessa-тесты с файлом настроек tools/vrunner.init.json | Прогон под другим файлом настроек, активный профиль не меняется |
| Запусти xunit-тесты | Сборка тестовых обработок и прогон |
| Запусти yaxunit-тесты | Прогон модулей тестового расширения |
| Проверь синтаксис конфигурации | Синтаксическая проверка, ошибки в ответе |
| Построй Allure-отчёт | Отчёт откроется в браузере |
| Настрой тестовые фреймворки: включи vanessa и yaxunit | В панели тестирования останутся только они |

Упавшие тесты и отсутствие отчёта агент показывает как неудачу — «успешно» только когда тесты действительно прошли.

## Конфигурация

| Что написать | Что произойдёт |
|---|---|
| Загрузи конфигурацию из исходников | Конфигурация базы обновится из src/cf |
| Загрузи изменения конфигурации от коммита HEAD~1 | Загрузятся только изменённые объекты |
| Выгрузи конфигурацию в исходники | Обновятся файлы в src/cf |
| Собери 1Cv8.cf из исходников | Файл конфигурации появится в build/out |

## Расширения

| Что написать | Что произойдёт |
|---|---|
| Загрузи расширения из исходников | Загрузятся все расширения проекта |
| Загрузи расширение yaxunit-test | Загрузится только оно |
| Выгрузи расширение _ДемоРасширение в исходники | Обновятся файлы расширения в src/cfe |

## Информационная база

| Что написать | Что произойдёт |
|---|---|
| Создай пустую информационную базу | Файловая база в build/ib |
| Обнови конфигурацию информационной базы | Конфигурация базы приводится к исходникам |
| Обнови базу данных | Обновится структура базы |

## Обработки и отчёты

| Что написать | Что произойдёт |
|---|---|
| Собери внешние обработки | Обработки из src/epf соберутся в build/out/epf |
| Собери внешние отчёты | Отчёты из src/erf соберутся в build/out/erf |
| Запусти обработку build/out/epf/_ДемоЗаполнениеКонтрагентов.epf в Предприятии | Обработка выполнится в базе активного профиля |

## Сценарий: инициализация и прогон

Сценарии инициализации помечены тегом и живут в отдельном файле настроек, основной набор их исключает.

1. Покажи состояние окружения 1С
2. Запусти vanessa-тесты с файлом настроек tools/vrunner.init.json
3. Запусти vanessa-тесты

Шаг 2 выполнит только сценарии инициализации, шаг 3 — основной набор без них.

## Сценарий: работа под другим профилем

1. Переключись на профиль test
2. Обнови конфигурацию информационной базы
3. Запусти vanessa-тесты
4. Переключись на профиль default

Команды между шагами 1 и 4 выполняются в базе профиля test.

## Сценарий: база с нуля

1. Создай пустую информационную базу
2. Загрузи конфигурацию из исходников
3. Загрузи расширения yaxunit и yaxunit-test
4. Обнови базу данных
5. Запусти yaxunit-тесты

## Сценарий: правки под контролем проверок

1. Проверь синтаксис конфигурации
2. Загрузи изменения конфигурации от коммита HEAD~1
3. Проверь синтаксис конфигурации
4. Запусти yaxunit-тесты
