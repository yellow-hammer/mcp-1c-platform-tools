# Участие в разработке

## Требования для разработки

- Node.js 20+
- Расширение VS Code [1c-platform-tools](https://marketplace.visualstudio.com/items?itemName=yellow-hammer.1c-platform-tools) (для проверки работы с окном)

## Проверка и отладка

### Добавление MCP вручную

В **VS Code** при установке расширения из VSIX MCP регистрируется автоматически. В **Cursor** — нужен ручной конфиг. Создайте в проекте 1С `<проект_1С>/.cursor/mcp.json`. Путь в `args` задаётся относительно корня открытого проекта. Сервер находит окно по каталогу, из которого его запустили.

Пример: репо `mcp-1c-platform-tools` лежит рядом с проектом (например `ssl_3_1` и `mcp-1c-platform-tools` в одной родительской папке). В проекте `ssl_3_1` создайте `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "mcp-1c-platform-tools": {
      "command": "npx",
      "args": ["-y", "tsx", "../mcp-1c-platform-tools/src/index.ts"]
    }
  }
}
```

Если репо в другом месте — укажите в `args` полный или относительный путь к `src/index.ts`. После сборки: `"command": "node"`, в `args` путь к `out/src/index.js`. Запускайте из папки проекта. После изменений перезапустите Cursor.

### Проверка работы

1. **Расширение**  
   Откройте проект 1С в окне с 1C: Platform Tools и доверьте папке.

2. **Проверка через агента**  
   Напишите агенту, например: *«Загрузи конфигурацию из исходников в ИБ для проекта C:\путь\к\моему-1с-проекту»* (подставьте путь к папке с `packagedef`). Должен вызваться MCP-инструмент и команда расширения.

### Отладка расширения 1c-platform-tools

В workspace с обоими репозиториями запустите **Run Extension + MCP**. В открывшемся окне откройте проект 1С и вызовите инструмент: точка останова в `channelServer.ts` сработает.

## Сообщения

Рутинное подтверждение («конфиг записан») показывайте через `notifyQuiet` из `src/notify.ts`: строка состояния и запись в журнал. Всплывающее окно оставляйте для ошибки, предупреждения и сообщения с кнопкой.

## Установка и сборка

В корне репозитория:

```bash
npm install
npm run build
```

После сборки точка входа сервера: `out/index.js`.

Запуск собранного сервера:

```bash
node out/index.js
```

Сервер работает по протоколу MCP через `stdio` (stdin/stdout).

## Режим разработки

Запуск без предварительной сборки (через `tsx`):

```bash
npm run dev
```

В конфиге MCP при отладке можно указать `tsx src/index.ts` вместо `node out/index.js` (при этом `cwd` — корень репозитория).
